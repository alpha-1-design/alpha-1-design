### About the developer

**Hi. I'm Samuel — a developer from Ghana and the builder behind [Alpha-1 Studio](https://alpha1studio.vercel.app/).**

I think most software is built backwards. Apps upload your data to someone else's server and call it a feature; you pay with privacy and never really own your tools. I believe the opposite: **privacy should be the default, not a feature** — so I build things that run *on your device*, architected so data collection is *impossible*, not merely optional.

- 🧠 **Obsessed with agentic AI** — not chatbots. Software that uses your machine the way you would: a real terminal, your real files, your real screen, and a brain that can act on them offline.
- 📱 **Ship for both worlds** — Android apps (Capacitor, native Java/Kotlin plugins) and native Linux desktop (Tauri + Rust). One brain, two canvases.
- 🏠 **Local-first by conviction** — on-device LLMs (Transformers.js/ONNX), local Whisper, local TTS. The hardware you already own is the server.
- 🔭 **Also a monitor of everything** — live Earth: aircraft, weather, space weather, news. If it's happening somewhere on the planet, I probably built a globe for it.
- ⚒️ **Builder through and through** — a workshop of tools rather than a single repo: security toolkits, AI agents, monitoring consoles, offline utilities. Everything is public here.

> **My rule:** if it doesn't respect your data, it doesn't ship.

### Flagship: GIA — Generative Interface Agent

**A full AI workspace that runs entirely on-device.** No backend. No account. No telemetry. A genuine agentic AI you can install and use offline — and now, on your desktop.

- **🚀 Now on Linux (desktop)** — GIA Cowork, built with Tauri + Rust: a real terminal, your files, a sandbox, a floating orb that watches your screen and acts for you (observe → act → verify), full window daemon, and self-updating releases
- **📲 Android companion app** — same brain on your phone: wake-word voice, on-device Whisper transcription, local TTS, and a floating Jarvis orb you can *talk to*
- **🔗 Phone ↔ desktop pairing** — Cross-Device mesh over your LAN: capability profiles swap, sensors meet shell, one brain across two screens
- **21+ AI providers** — Anthropic, Google, OpenAI, Groq, Mistral, xAI and more, hot-swappable
- **270+ tools** — a real agentic tool loop executing client-side, governed by per-capability policy (allow / ask / deny)
- **Multi-tier memory** — working, semantic, and episodic
- **MCP protocol support** + plugin system + security hardening
